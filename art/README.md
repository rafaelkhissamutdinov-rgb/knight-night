# Арт из PixelLab (заготовки, ещё не в игре)

Сгенерировано в v0.58 через `tools/pixellab.py`. Ключ — переменная окружения `PIXELLAB_API_KEY`.

- `pixellab/knight-clean/` — стройный Найт, 16 вариантов (`sheet.png` — все сразу). Владелец выбрал **№10** (`kn2_09.png`) как основу.
- `pixellab/knight-worn/` — потёртая стартовая броня от №10, 16 вариантов: ждёт выбора владельца.
- `pixellab/knight-night/` — **Найт для игры**: потёртый №10 без оружия (меч рисуется кодом), 8 ракурсов (`rot-*.png`), стойка с дыханием (`idle-*`, 4 кадра) и ходьба (`walk-*`, 6 кадров), вид сбоку. Персонаж в PixelLab: `character.json` (id для новых анимаций).
- `pixellab/boss/` — призрак главы стражи по костюму владельца, 9 вариантов 80 px.
- `pixellab/portraits/alkima_*.png` — 16 вариантов портрета Алкимы; в игре — `alkima_00` (`assets/portraits/alkima.png`).
- `pixellab/rooms/dungeon-wall.png` (+ `-normal`) — проба фона Темницы 320×180. Свет в нём нарисован — для игры фоны заказывать равномерно освещёнными, свет даёт шейдер.
- `light-demo/` — демо живого света (WebGL, карты нормалей, факелы, пыль). По умолчанию — выбор владельца: свет ступенями, «Тёплое» настроение, без фонаря. Открывать через локальный сервер: `python3 -m http.server` в этой папке.

Цены (Tier 2): портрет/вариант персонажа `generate-image-v2` 64×64 ×16 = 10 генераций; персонаж в 8 ракурсах `create-character-v3` 64 px ≈ 2; анимация по скелету `animate-with-skeleton-v3` 3–15 кадров = 2–4; карта нормалей 0,5; фон 320×180 ≈ 10.
