# Knight Night — дизайн игры

Живой документ: записываем решения владельца и открытые вопросы.

## Суть

Пиксельное приключение про рыцаря, проходится за 30–60 минут. 4–5 локаций, врагов немного, есть небольшая история. Рыцарь идёт по локации, враги появляются по пути и вызывают на дуэль. Элементы рогалика — под вопросом.

## Главная механика: парирование по высоте

1. **Враг показывает удар движением.** Есть короткая пауза-замах, по позе видно, куда придёт удар:
   - сверху — меч занесён над головой → верхняя защита;
   - по корпусу — меч отведён сбоку, враг наклоняется → средняя защита;
   - снизу — враг приседает, меч внизу → нижняя защита.
2. **Защиту двигают стрелками:** ↑ верх, → середина, ↓ низ.
3. **Обычный блок** — нужная защита уже стоит, когда приходит удар. Урона нет.
4. **Идеальное парирование** — нужную стрелку нажали прямо перед ударом (окно `perfectWindow` в `src/config.js`).
5. **Серии ударов.** Враг бьёт сериями: «тыщ-тыщ», например середина → верх.
6. **Контратака.** Если вся серия отбита идеально, враг ошеломлён и можно сделать выпад (Z) с повышенным уроном. После обычной серии враг ненадолго открыт для простого удара.
7. **Комбинации поз** — для атак рыцаря, а не для защиты. Пока не сделано.

## Что есть в прототипе

- Коридор подземелья, 3 врага по нарастающей: Стражник, Наёмник, Капитан стражи.
- Защита ↑ → ↓, блок и идеальное парирование, защита от «спама» кнопками.
- Ошеломление после идеальной серии, выпад ×3, обычный удар ×1.
- Отклик: хитстоп, искры, тряска, вспышка, звуки. Блик на клинке в момент «жми сейчас», короткий звук разной высоты на замахе (можно выключить в конфиге).
- G — отладка: полоса замаха и окно идеального парирования, тайминг последнего нажатия.
- Смерть → бой с этим врагом заново.

- Есть ли у врага защита от атак рыцаря и обманные замахи (финты)?
- Нужна ли выносливость (стамина) или блок бесплатный?
- Рогалик: что сохраняется между забегами, генерируются ли комнаты?
- История: кто рыцарь, куда идёт, 4–5 локаций — какие?
- Блик и звук-подсказка — оставить, сделать опцией для лёгкого режима или убрать?
