## Второй адрес игры (Netlify) — 5 минут, нужен твой вход

GitHub Pages остаётся как есть. Netlify — второй адрес той же игры; с ним репозиторий можно потом закрыть (сделать приватным), а игра по ссылке Netlify продолжит работать. Мне войти в Netlify нельзя — это твой аккаунт.
1. Зайди на netlify.com → «Sign up» → «Continue with GitHub».
2. «Add new site» → «Import an existing project» → GitHub → выбери `knight-night`, ветка `main`.
3. Настройки сборки уже в репозитории (`netlify.toml`): ничего не меняй → «Deploy». Через минуту будет ссылка вида `что-то.netlify.app` — её можно переименовать в «Site settings → Change site name».
4. Проверь игру по новой ссылке. Если всё работает и хочешь спрятать код: GitHub → репозиторий → Settings → внизу «Change visibility» → Private. Тогда старая ссылка GitHub Pages перестанет работать (на бесплатном тарифе), Netlify — останется.
Важно: код любой браузерной игры всё равно скачивается в браузер игрока. Приватный репозиторий прячет историю, черновики, документы и инструменты, но не саму игру.

## Сложность — твоё решение

Замок (глава 1) теперь собран — ты откладывал сложность до этого момента. Я **не менял** обычный баланс, только добавил необязательный **«Лёгкий режим»** в паузе (шире окно идеального, замахи медленнее). Варианты дальше:
- оставить лёгкий режим как есть (для новичков) и не трогать обычный;
- смягчить обычный (например, враг закрывается после двух пропущенных ударов, Бубновый туз лечит);
- оставить как есть — сложно, но честно.
