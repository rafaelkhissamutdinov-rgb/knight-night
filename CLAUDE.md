# Knight Night — заметки для работы над проектом

Маленькая пиксельная игра про рыцаря: короткое приключение на 4–5 локаций (30–60 минут), главная механика — парирование ударов по высоте. Владелец — креативный директор проекта, сам не программирует. Общение на русском, прямо, без воды. Работа идёт короткими сессиями по вечерам, цель — к Новому году 2027.

Дизайн игры и принятые решения — в `docs/design.md`. Перед изменением механики свериться с ним и обновить его, если владелец что-то поменял.

## Стек и команды

Vanilla JS (ES-модули), Canvas 2D, без сборки и зависимостей. Звук синтезируется WebAudio.

```bash
npm test     # node --test: правила боя и поведение врага (src/combat.js, src/enemy.js)
npm start    # python3 -m http.server 8080 → http://localhost:8080
```

Модули нельзя открыть через `file://` — нужен локальный сервер.

Проверка в браузере: Playwright + Chromium уже стоят в облачной среде (`NODE_PATH=$(npm root -g) node script.js`). Состояние игры доступно как `window.knightNight` — по нему бот может проходить бои.

## Структура

- `src/config.js` — **все числа баланса**: окно парирования, урон, `WEAPON` (меч: удары и перемещения рыцаря), `RAPIER`, `ENEMY_TYPES`, `NPC_TYPES`, `ITEMS`, мир из комнат `ROOMS` (двери, края, встречи, декорации) и `START`, `VERSION`. Правки баланса — сюда. При заметном изменении поднимать `VERSION`.
- `src/combat.js` — чистые правила: исход удара врага или стрелы (dodged / warded / perfect / block / hit + множитель урона), зона попадания по слизню.
- `src/enemy.js` — враги: `createEnemy(type, x)`. Классы Melee (dormant → approach → idle → windup → strike → recover | stagger), Archer (держит дистанцию, hop, стрелы), Slime (hop, crouch → leap, retreat → inflate → suck). Враги закрываются от ударов рыцаря (`notifyAttack`, `guardChance`), удар во время их замаха — размен.
- `src/player.js` — рыцарь: ready / attack (windup → active → recover) / dash / backdash / roll / hurt / swallowed. `chooseAttack` выбирает удар по вводу, ножны, отмена замаха, буфер ввода.
- `src/poses.js` — позы (кисть, угол клинка, наклон, присед). Замах должен читаться по силуэту.
- `src/draw.js` — пиксельные примитивы и фигура бойца-заглушки.
- `src/sprites.js` — спрайт Найта (v0.60): кадры `assets/sprites/knight/` (+ `knight.json`: точка кисти каждого кадра), ближайшая поза из `src/poses.js`, меч/рапира рисуются кодом от кисти. Холст 640×360, мир — 320×180, масштаб `S = 2` в `src/main.js`.
- `src/lighting.js` — живой свет (v0.62): WebGL-проход поверх 2D-сцены, источники — `sceneLights()` в `src/main.js`; нормали спрайтов — `assets/sprites/knight/n/`.
- `src/palette.js` — цвета.
- `src/main.js` — цикл (фиксированный шаг 1/60 с), режимы title / play / dead / end, ввод (направления относительно взгляда рыцаря), объект `world` для врагов, стрелы, столкновения тел, эффекты, HUD.
- `index.html`, `style.css` — страница; HUD, надписи и окно диалога — DOM поверх canvas.
- `src/dialogue.js` — движок диалогов; `src/story/dialogues.js` — тексты (черновики) и `SHOPS` — реплики, товары и темы лавок; `docs/story.md` — сюжет владельца.
- `src/story/bestiary.js` — страницы журнала (бестиарий): как бьёт, как победить, описание врага.
- `src/tutorial.js` — шаги обучения у наставницы (чистая логика, есть тесты). `src/save.js` — сохранение в localStorage.
- `assets/portraits/` — портреты для диалогов (v0.63: **все перерисованы в PixelLab в одном стиле** — 64×64, увеличены до 256; Илиа и Лика — по описанию фото людей, с которых списаны, с их согласия; Найт — под потёртую броню №10; настроения Лики и усталый Найт — правкой портрета `edit-image-pixen`; варианты — `art/pixellab/portraits/sheets/`). Прежнее описание: **вырезанные без фона** (256×256 PNG с прозрачностью): `knight.png` — обычный, `knight-tired.png` — прищур (`mood: 'tired'`), `knight-nohelm.png` — без шлема (`mood: 'nohelm'`), `ilia.png`, `alkima.png` (наставница; сгенерирован в PixelLab по картинке владельца в стиле портрета Лики, волосы чёрные), `lika.png` и `lika-<настроение>.png` (happy, sly, surprised, sulky, serious, worried, angry; в лавке — `moods` в `SHOPS`, в диалогах — `mood` у реплики). Фон вырезается нейросетью: `pip install "rembg[cpu]"`, модель `birefnet-portrait` (лучше всего держит плюмаж и кольчугу), край — порог альфы 110. Подключаются в `FACES` в `src/main.js`.
- Фоны-картинки: движок умеет (`image`, `tile`, `flames` у комнаты в `ROOMS`, `buildImageRoom`), но **сейчас все комнаты рисуются кодом** — решение владельца (v0.32): его картинки Караульной и Галереи убраны, двери на них «летали». Старые файлы — в истории git (`assets/backgrounds/`). Картинку с дверями принимать, только если у пола есть место под двери 22×36.
- `src/background.js` — фон комнат (стены, двери, решётки), факелы, портал, бочки, паутина, темнота.
- `src/title.js` — титульный экран (замок на горе, башня мага, Найт на уступе), рисуется кодом.
- Карта замка — `MAP` в `src/config.js` (этаж, x, y, ширина в клетках), рисует `renderMap` в `src/main.js`; комнаты открываются флагами `map_<комната>`.
- Места отдыха — `rest` у пропа или убранства (диван, камин, скамья, костёр): сесть, лечение, сохранение; «продолжить» — с последнего (`flags.restAt`).
- Жизнь и щит — шкалы (v0.59): щит от брони (`shield` у предмета) принимает урон первым (`splitDamage` в `src/combat.js`), восстанавливается без попаданий. Сеты — `SETS` в `src/config.js` (сет мародёра: три свёртка `loot` по комнатам → броня, `speed` — множитель ходьбы).
- Комната может начинать разговор при входе (`enterTalk: { id, needs }`); NPC появляется по флагу (`needs`), может сидеть (`sit` в `NPC_TYPES`). Привал (`camp`) — Илиа у костра после победы над ним.
- Сюжетные бои — `story` у встречи (не респавнятся, победа — флаг `done_<имя>`). Дверь `needs` — появляется после флага; `requires` — заперта до флага; `finish` — конец демо (`finishTitle`).
- Второй этаж (черновик Claude, ждёт лор владельца): `landing2`, `hall2`, `library` (+ тайная `reading`), `chapel`, `vestry`, `stairs3`.
- Третий этаж (по плану владельца): `landing3`, `hall3` (пролом `fall` вниз к башне, завал наверху), `guardhall` (ключ от башни). Башня → дверь наверх (покои принцессы) — конец главы 1; финальный босс — призрак главы королевской стражи (решение владельца v0.57, маг — позже), не сделан; комната `mage` («Покои принцессы») недоступна.
- Двери: `fall` — прыжок в пролом (падение, другая комната); `oneWay` — без обратной двери (тест это учитывает); `stairs` — лестница: шаг и затемнение, без проёма в стене (решение владельца).
- `docs/owner-todo.md` — напоминания владельцу (тексты перечитать, картинки, вопросы по лору). Пополнять, когда что-то ждёт владельца.
- `tools/lika_moods.py` — как подгонялись настроения Лики под оригинал (уже применено).
- `tools/pixellab_poses.py` — позы `src/poses.js` → скелеты PixelLab (кисть по IK) → кадры Найта; итог — `art/pixellab/knight-night/poses/` (+ `wrists.json` — где кисть, от неё рисуется меч).
- `tools/pixellab.py` — клиент PixelLab (генерация пиксель-арта); ключ — переменная окружения `PIXELLAB_API_KEY`, в репозиторий не класть. `generate-image-v2` с `style_image` (портрет-образец 64×64) и `reference_images` (картинка персонажа) держит стиль портретов; 16 вариантов 64×64 = 10 генераций. Пример — `tools/pixellab_alkima.py`.
- `src/decor.js` — убранство стен (`decor` у комнаты): окна, знамёна, портреты, гобелен, стойки, нары, кандалы, доспех, камин, люстра, плющ. `look` — разговор при осмотре (E).

Ветки: `main` — то, что видит тестер (GitHub Pages публикует `main`); `claude/parry-prototype` — старый бой в одной плоскости (v0.4); `claude/depth-prototype` — вариант A, слит в `main` в v0.8. Новые изменения — в ветке от `main`, затем PR в `main`.

## Решения владельца

- Управление (после бета-теста): курсор выбирает высоту, ЛКМ — удар, держать ПКМ — защита, пробел — рывок, WASD — ходьба. Других схем нет.
- Колесо — приём оружия (меч: вихрь, рапира: восьмёрка), перезарядка 4 с. Q — смена оружия.
- Начало: рыцарь отмечает порталы на карте; появляется в тёмной камере заброшенного замка, наставница учит драться (вместо чучела), торговка Лика — в отдельной лавке с меню как в Undertale. Тексты пишет владелец; всё в игре с пометкой [черновик].
- Второе оружие — рапира: её выбивают у Илиа последним ударом, он отступает. Набор приёмов — `RAPIER` в `src/config.js`, описание — `docs/design.md` (v0.12).

- **Графика (v0.58, решение владельца):** делаем в PixelLab (`tools/pixellab.py`, заготовки — `art/`). Экран расширяем до **640×360** (целое масштабирование: ×3 = 1920×1080, потом полноэкранный режим), персонажи ≈ 64 px. Раньше было 320×180 и 32×32 — отменено.
- Найт — стройный, изящный, средне-высокого роста (не коренастый), основа — вариант №10 (`art/pixellab/knight-clean/kn2_09.png`). Стартует в **потёртой** броне и со старым мечом; броню и оружие можно менять (броня — «состояния» персонажа PixelLab с теми же позами скелета, оружие рисуется отдельно кодом по углу клинка).
- Свет — шейдером (WebGL, карты нормалей), не фильтрами. Выбор владельца: живой свет, **свет ступенями** (пиксельные кольца, не плавно), **пыль в воздухе**, настроение **«Тёплое»**. Фонаря у рыцаря нет (может стать предметом позже). Демо — `art/light-demo/`. Фоны заказывать равномерно освещёнными.
- Спрайты — PNG-листы, чтобы владелец мог править их в Piskel / Aseprite.

## Процесс

- Работа в ветке → PR в `main`. Репозиторий публичный.
- После изменений: `npm test` и прогон в браузере (без ошибок в консоли).
