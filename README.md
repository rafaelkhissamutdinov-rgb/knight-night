# Knight Night

Пиксельное приключение про рыцаря, который парирует удары по высоте: сверху, по корпусу, снизу. Сейчас это прототип механики на простых фигурах.

## Как запустить

```bash
npm start          # или: python3 -m http.server 8080
```

Открыть http://localhost:8080. Нужна клавиатура.

## Управление

| Ввод | Действие |
|---|---|
| ← → | идти |
| ↑ / ↓ / назад от врага | защита сверху / снизу / по корпусу |
| ЛКМ (+↑ / ↓) | удар сбоку (сверху / снизу) |
| ПКМ | рывок; с «назад» — отскок с заслоном, с ↓ — кувырок, с ↑ — прыжок с ударом |
| вперёд, назад, ЛКМ | вихрь |
| G | отладка |

Без мыши: J — удар, K или пробел — рывок. Подробно — в `docs/design.md`.

## Баланс

Все числа (окно парирования, урон, скорость замахов, серии ударов врагов) — в `src/config.js`.

Подробности дизайна — `docs/design.md`.
