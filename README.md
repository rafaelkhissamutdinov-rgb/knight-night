# Knight Night

Пиксельное приключение про рыцаря, который парирует удары по высоте: сверху, по корпусу, снизу. Сейчас — прототип на фигурах, нарисованных кодом: глава 1 (заброшенный замок, три этажа) проходится от камеры с порталом до двери в покои принцессы; финальный босс — призрак главы стражи — будет позже.

## Как запустить

```bash
npm start          # или: python3 -m http.server 8080
```

Открыть http://localhost:8080. Нужны клавиатура и мышь.

## Управление

| Ввод | Действие |
|---|---|
| WASD | ходить вбок и вглубь пола |
| курсор выше / на уровне / ниже груди рыцаря | высота: верх / середина / низ |
| ЛКМ | удар на выбранной высоте |
| держать ПКМ | защита на выбранной высоте |
| пробел | рывок: внизу — кувырок, вверху — прыжок с ударом, с «назад» — отскок |
| колесо вверх | вихрь (перезарядка 4 с); с рапирой — восьмёрка |
| колесо вниз | навык из слота (свиток: «Тройной выпад» для рапиры, «Тяжёлый удар» для меча) |
| Q | сменить меч и рапиру (рапиру выбивают у Илиа и подбирают) |
| W у двери | войти в дверь; у пролома — спрыгнуть |
| E | поговорить, лавка, сундук, осмотреть, отдохнуть (диван, камин, скамья — сохранение) |
| I / B / M / H | снаряжение и сумка / журнал врагов / карта замка / выпить зелье |
| Esc | пауза: меню, управление, звук, музыка, лёгкий режим, новая игра, отчёт для тестера |
| F3 | отладка |

Рапира: быстрые клики — до трёх уколов подряд; вверху щелчок — захлёст (огибает защиту), держать ЛКМ — прыжок через врага с захлёстом (перезарядка 3 с); два блока подряд — рипост.

В диалогах: ЛКМ или Enter — дальше, 1–3 — выбор ответа. Подробно — в `docs/design.md`, сюжет — в `docs/story.md`.
