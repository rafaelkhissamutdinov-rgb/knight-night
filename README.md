# Knight Night

Пиксельное приключение про рыцаря, который парирует удары по высоте: сверху, по корпусу, снизу. Сейчас это прототип механики на простых фигурах.

## Как запустить

```bash
npm start          # или: python3 -m http.server 8080
```

Открыть http://localhost:8080. Нужна клавиатура.

## Управление (схема «мышь», по умолчанию)

| Ввод | Действие |
|---|---|
| WASD | ходить вбок и вглубь пола |
| курсор выше / на уровне / ниже груди рыцаря | высота: верх / середина / низ |
| ЛКМ | удар на выбранной высоте |
| держать ПКМ | защита на выбранной высоте |
| пробел | рывок: внизу — кувырок, вверху — прыжок с ударом, с «назад» — отскок |
| вперёд, назад, ЛКМ | вихрь |
| C | переключить на схему «колесо» (колесо — стойки, W/S + ЛКМ — удары, ПКМ — рывок) |
| G | отладка |

В диалогах: ЛКМ или Enter — дальше, 1–3 — выбор ответа. Подробно — в `docs/design.md`, сюжет — в `docs/story.md`.

## Баланс

Все числа (окно парирования, урон, скорость замахов, серии ударов врагов) — в `src/config.js`.

Подробности дизайна — `docs/design.md`.
